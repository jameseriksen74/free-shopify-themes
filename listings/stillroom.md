# Listing copy: Stillroom

**Title (short):** Stillroom: Free Shopify Theme
**Title (long):** Stillroom: Free Clean minimal Shopify Theme (Online Store 2.0) by Pretty Things Online

**One-liner:** A quiet, minimal theme with a split hero, glassy header and lots of white space that lets products speak.

**Description:**
Stillroom is a free, modern Shopify theme from Pretty Things Online. A quiet, minimal theme with a split hero, glassy header and lots of white space that lets products speak. It's built on Online Store 2.0, so every page is made of drag-and-drop sections, and it ships with three colour presets (Stillroom (white and ink), Stone, Ocean) so you can find your look in one click. It's fast (one stylesheet, one tiny script, no jQuery), accessible, and passes Shopify Theme Check with zero issues. Perfect for skincare, electronics, furniture, coffee, fashion basics.

**Features:**
- Online Store 2.0: JSON templates, sections everywhere, header and footer section groups
- Hero banner (3 layouts), featured collection, collection list, image with text, rich text, testimonials, newsletter, Custom Liquid and Apps sections
- Product page with image gallery, pill-style variant picker, quantity, dynamic checkout buttons, Shop Pay installments, pickup availability, collapsible tabs and related products
- Collection filtering (Shopify Search & Discovery filters) and sorting
- Predictive search in the header
- Cart page with order notes, discounts, unit prices and accelerated checkout buttons
- Customer accounts, blog, contact page, password page and gift card templates
- 3 colour presets, font pickers, corner radius and page width controls
- Lightweight: one CSS file, one small vanilla JS file, no jQuery, no app dependencies
- Accessible: skip link, visible focus styles, keyboard friendly menus, reduced motion support
- Passes Shopify Theme Check with 0 errors and 0 warnings
